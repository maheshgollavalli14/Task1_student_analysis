#  Student Performance Analysis Using Python

---

##  About the Project

The main goal of this project is to analyze student performance data using Data Analytics techniques and Python libraries.

In this project, I worked with student datasets to:
- Clean and process data
- Analyze student marks
- Find useful insights
- Visualize performance using graphs

This project helped me understand the basics of Data Science and Data Analytics.

---

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

##  Dataset Information

The dataset contains:
- Student Scores
- Reading Marks
- Writing Marks
- Math Scores
- Student-related details

---

##  Project Features

- Data Cleaning  
- Data Analysis  
- Average Score Calculation  
- Maximum & Minimum Score Analysis  
- Data Visualization  
- Performance Insights
